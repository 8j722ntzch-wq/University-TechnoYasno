# ТехноЯсно

Учебный магазин компьютерной техники. В каталоге 21 демонстрационный товар, включая 12 ноутбуков. Цены указаны в BYN. Корзина, избранное и сравнение сохраняются в браузере. Заказ, запрос предложения и резерв в шоуруме демонстрируют интерфейс без отправки данных.

## Запуск

В проверенной среде используется Node.js 26.13. Установите зависимости командой `npm install` (для точного воспроизведения lock-файла — `npm ci`). Команда `npm run dev` запускает разработку. После `npm run build` выполните `npm run preview` для просмотра статической сборки. Команда `npm test` проверяет поиск, подбор и расчёт корзины.

Для просмотра без установки откройте TechnoYasno.html в браузере. Сборка обновляет этот файл и папку dist/. Многостраничная сборка рассчитана на корень домена. Для демонстрации через GitHub Pages в подпапке репозитория можно разместить автономный HTML как index.html.

## Материалы

Данные товаров находятся в src/lib/products.json. Матрица девяти шаблонов и сценариев — в docs/prototypes.md. Контрольный запрос для поиска — DEMO-001. Цена Lenovo IdeaPad Slim 3 15 составляет 1 699 BYN, с курьерской доставкой по Минску — 1 709 BYN.
